# Crystal Setup

- Download Crytal at **[Official Github](https://github.com/crystal-lang/crystal/releases)**
- Download it for your OS **(This was tested on Windows 11 Pro)**

**If you set it Up Run this to Check if you Really installed it:**
```yaml
crystal -v
```
```yaml
shards --version
```

Then Install [discordcr](https://github.com/shardlab/discordcr)
Make sure its in your Root Folder "lib"
If it Returns a Version, you Know you have installed it.
