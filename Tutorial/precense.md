# Activity Types

Use these constants to set the activity type for your bot:

| Type | Constant |
| :--- | :--- |
| Playing | Discord::GamePlaying::Type::Playing |
| Streaming | Discord::GamePlaying::Type::Streaming |
| Listening | Discord::GamePlaying::Type::Listening |
| Watching | Discord::GamePlaying::Type::Watching |
| Custom | Discord::GamePlaying::Type::Custom |
| Competing | Discord::GamePlaying::Type::Competing |

# Requirements

* discordcr shard
* A valid bot token
